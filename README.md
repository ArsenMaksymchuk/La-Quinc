# La Quinc’ — сайт бара (Нанси)

Многоязычный сайт: 2 Rue St Nicolas, 54000 Nancy, тел. 07 71 80 22 52. Бар «Bière & Rhumerie».

- Один файл `index.html` (логотип и фото встроены), без сборки
- Языки: FR (по умолчанию), EN, DE, IT, ES
- Меню коктейлей с доски (17 позиций, 4–8 €) + фильтры (мохито, ром, водка, текила и виски, безалкогольные) + кнопка «Удиви меня!»
- Реалистичный 3D-мохито в начале (стекло с отражениями, лёд, мята, лайм, пузырьки)
- 3D-эффект на кнопках: вылетают бокалы, пинта, шот, лёд, лайм, вишня
- Мини-карта (схематичная SVG) + «Открыть в Google Maps»
- Логотип (круглый) в шапке, футере и favicon
- Часы: известно только «открывается в 18:00»

## Как менять
Меню — массив `MENU`; тексты — объект `T` (fr — в HTML, `data-i`).

## Проверить
Часы работы (закрытие, дни), цены с доски (читались с фото), Facebook-ссылка (нет URL), права на фото.
